    Notes for the tester

    • The phrase plays through the server proxy at /api/tts. If you hear nothing, the server is missing ELEVENLABS_API_KEY.
    • Each voice ID must be in ELEVENLABS_ALLOWED_VOICES on the server (comma-separated). The proxy rejects unknown IDs with 400 invalid_voice.
    • After picking, commit your choice to .env.example as a comment so the next person starts from there.
